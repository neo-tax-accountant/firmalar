# Тестлар — «Фирмалар базаси (дастур)»

Бу папка дастурнинг автомат текширувларини сақлайди. Мақсади битта:
**янги функция қўшилганда эски бўлимлар жимгина бузилиб қолмасин.**

Тестлар дастурни ҳақиқий браузерда (Chromium) очади, демо маълумотлар
билан ишлатиб кўради ва натижани текширади. Ҳеч қандай ҳақиқий Google
аккаунти, Claude калити ёки интернет сўрови ишлатилмайди — Claude
жавоблари тест ичида сохта қилиб берилади.

---

## Ишга тушириш

```bash
bash tests/setup.sh      # бир марта: Chromium ва кутубхоналарни ўрнатади
bash tests/run_all.sh    # барча тестлар
bash tests/run_all.sh t_50   # фақат номида t_50 борлари
```

Ҳар бир тест охирида `ERR []` чиқиши керак — бу JavaScript хатоси
йўқлигини билдиради. Охирида умумий натижа кўрсатилади.

Скриншотлар ва юклаб олинган файллар `tests/out/` папкасига тушади
(бу папка GitHub'га юкланмайди).

## Янги тест ёзиш

Янги бўлим қўшилганда унга тест ҳам ёзилади. Андоза:

```python
import os
exec(open(os.path.join(os.path.dirname(os.path.abspath(__file__)),"harness.py")).read())

with sync_playwright() as p:
    b, pg = page(p); G = pg.evaluate
    pg.on('dialog', lambda d: d.accept())          # confirm/alert'ларга «ҳа»

    G('go({view:"firm", firmId:"namuna01", tab:"bank"})'); pg.wait_for_timeout(300)
    pg.set_input_files('#bkFiles', FIX+'bank.xlsx'); pg.wait_for_timeout(1500)

    print('натижа', G('V.bkImp.items.map(i=>i.status)'))
    pg.screenshot(path=OUT+'bank.png', full_page=True)
    b.close(); ok()
```

Фойдали чақириқлар:
- `G('...')` — дастур ичида JavaScript бажаради ва натижани қайтаради.
- `go({...})` — бўлимлар орасида ўтиш.
- `firm("namuna01")` — демо фирма; `S.recs`, `S.gtd` — маълумотлар.
- `putItem("recs", obj, "изоҳ")` — тест учун ёзув қўшиш.
- `FIX` — `fixtures/` папкаси, `OUT` — `out/` папкаси.
- `ok()` — охирида. JavaScript хатоси бўлса, тест йиқилади.

**Claude'ни сохталаштириш** (ҳақиқий сўров юборилмайди):

```python
G('''(()=>{ localStorage.setItem(AI_LK, JSON.stringify({key:"sk-test"}));
   aiDoc = async (file, f, spec, name) => ({x:{number:"1", date:"2026-01-01"}, usd:0.01});

```

  (`python3 tests/t_50_bank.py`) ва чиққан хабарни ўқинг.
