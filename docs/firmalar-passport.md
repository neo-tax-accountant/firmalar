## 1. Мақсад ва фойдаланувчилар
- 20+ мижоз фирманинг реквизитлари, ҳужжатлари ва бухгалтерия ишларини битта жойда юритиш.
- Фойдаланувчилар: эгаси (бош бухгалтер) ва ёрдамчилар. Ҳамма маълумотни ҳамма кўради.
- Ким, қачон, нимани ўзгартиргани автоматик қайд этилади.
- Компьютер ва телефонда браузер орқали ишлайди.

## 3. Маълумотлар модели (Google Sheets варақлари)
| Варақ | Устунлар | Нима сақланади |
|---|---|---|
| firms | id, data, updatedAt, updatedBy, deleted | Фирмалар ва уларнинг реквизитлари |
| orders | — || — | Буйруқлар ва қарорлар |
| recs | — || — | Бошқа барча ёзувлар (шартномалар, чеклар, ҳисоботлар, AI харажатлари ва ҳ.к., `type` майдони билан) |
| gtd | — || — | ГТД реестри |
| emp | — || — | Ходимлар, лавозимлар (штат), таътил графиклари |
| log | at, email, name, kind, id, note | Ўзгаришлар журнали (ким, қачон, нима) |

Қоидалар:
- Ҳар бир ёзув `data` устунида JSON кўринишида сақланади.
- Ўчириш «юмшоқ»: `deleted` белгиси қўйилади, ёзув жисмонан ўчмайди.
- Бир вақтда таҳрирлашда зиддият (ConflictErr) аниқланади ва маълумот қайта юкланади.
- Ҳар бир ёзувда «ким ўзгартирди + сана/вақт» кўрсатилади, тарих `log` варағидан олинади.

## 5. Умумий (фирмалараро) бўлимлар
- **Барча фирмалар** — рўйхат, буйруқлар статуси бўйича ҳисоблагичлар.
- **Назорат маркази** — барча фирмалар бўйича назорат.
- **Контрагентлар** — умумий контрагентлар базаси.
- **Оммавий хат** — бир хил хатни бир нечта ташкилотга яратиш.
- **Такрорланган ҳужжатларни топиш** — барча бўлимлар бўйича дубликатлар.
- **Ҳужжатларни топшириш-қабул қилиш далолатномаси.**
- **Фирма архиви** — тўлиқ чиқариб олиш (ZIP), архивдан тиклаш, юклаб олинмаган файллар назорати.
- **Ҳужжатни QR орқали текшириш** — QR ҳақиқийликни текширади; ҳуқуқий кучни имзо беради (муҳр мажбурий эмас).
- **Claude AI** — API калити, модел танлаш, ойлик лимит, харажат журнали.
- **Созламалар.**

1. **Google API калити очиқ репозиторийда.** Бу браузер иловалари учун одатий ҳол, лекин Google Cloud Console’да калитни фақат `neo-tax-accountant.github.io` доменига ва фақат Sheets/Drive API’га чекланг.
