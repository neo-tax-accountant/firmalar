# Тиклаш йўриқномаси — «Фирмалар базаси (дастур)»

> Мақсад: ҳаммаси йўқолган ҳолатда дастурни ноль нуқтадан қайта ишга тушириш.
> Тузилган: 05.11.2026 (в70 ҳолатига).

---

## 0. Асосий тушунча

Дастурни **қайта ёзиб** тиклаб бўлмайди. 10 700 қатор код, 860 та функция —
уни тавсифдан туриб қайта яратиш бошқа дастур чиқаради, худди ўзини эмас.
Тиклаш деганда **сақлаб қўйилган `index.html` файлини қайтариш** тушунилади.

Шунинг учун бу ҳужжатдаги энг муҳим қоида битта:
**`index.html` файлининг камида учта жойда нусхаси турсин.**

---

## 1. Тўлиқ ишлаши учун керак бўлган 4 та нарса

| № | Нима | Қаерда туради | Йўқолса нима бўлади |
|---|---|---|---|
| 1 | `index.html` — дастурнинг ўзи | GitHub + компьютер + Drive | Дастур умуман йўқ |
| 2 | Google Sheets базаси | Сизнинг Google Drive'ингиз | Код ишлайди, маълумот бўш |
| 3 | Drive'даги файллар (PDF, сканлар) | Сизнинг Google Drive'ингиз | Ёзувлар қолади, файллар очилмайди |
| 4 | Google Cloud созламаси (CONFIG) | Google Cloud Console | Дастур очилади, кирилмайди |

Тўртинчиси энг кўп эсдан чиқади. Қуйида у алоҳида ёзилган.

---

## 2. Ҳолат А — янги версия бузилди, эскисига қайтиш керак

Энг тез-тез учрайдиган ҳолат. 5 дақиқалик иш.

1. `github.com/neo-tax-accountant/firmalar` ни очинг.
2. `index.html` файлини босинг → ўнг юқорида **History** (тарих).
3. Яхши ишлаган кунги юклашни танланг.
4. Ўша саҳифада **View file** → **Download raw file**.
5. Юкланган файлни репозиторийга қайта юкланг (`index.html` номи билан).
6. Сайтда **Ctrl+F5**. Пастки чап бурчакдаги версия белгиси эски версияни
   кўрсатиши керак.

**Маълумотга таъсир қилмайди.** База Google Sheets'да, код алмашганидан
маълумот ўзгармайди.

---

## 3. Ҳолат Б — GitHub репозиторийси йўқолди

1. GitHub'да янги репозиторий яратинг: `firmalar`, **Public**.
2. Сақлаб қўйилган `index.html` файлини юкланг (Add file → Upload files).
3. **Settings → Pages** → Source: `Deploy from a branch` → Branch: `main`,
   папка: `/ (root)` → Save.
4. 1–2 дақиқада сайт ишга тушади.
5. Янги манзилни Google Cloud'да рўйхатга қўшинг (4-бўлимга қаранг).
   Репозиторий номи ва аккаунт ўша бўлса, манзил ҳам ўша бўлади ва
   ҳеч нарса ўзгартирилмайди.

---

## 4. Ҳолат В — Google Cloud созламаси йўқолди (кириш ишламаяпти)

Дастур очилади, лекин «Google орқали кириш» ишламайди ёки демо режимга
тушиб қолади. Демак `CONFIG` қийматлари нотўғри.

`index.html` ичида, тахминан 1349-қаторда, шундай блок бор:

```
const CONFIG = {
  CLIENT_ID: "…apps.googleusercontent.com",
  API_KEY:   "AIza…",
  APP_ID:    "350226065898",
};
```

Бу учта қиймат **махфий эмас** — браузер иловаларида улар очиқ бўлади.
Махфий бўлгани — **client secret**, у кодда ҳеч қачон бўлмаслиги керак
ва ҳозир ҳам йўқ.

### Қайта созлаш тартиби

1. `console.cloud.google.com` → янги лойиҳа яратинг (ёки эскисини очинг).
2. **APIs & Services → Library** → иккитасини ёқинг:
   - Google Sheets API
   - Google Drive API
3. **OAuth consent screen**:
   - User type: **External**
   - Publishing status: **Testing** (шундай қолдиринг)
   - **Test users** рўйхатига ўз Gmail'ингизни ва ёрдамчиларникини қўшинг
   - Scopes: `drive.file`, `openid`, `email`, `profile`
4. **Credentials → Create credentials → OAuth client ID**:
   - Application type: **Web application**
   - **Authorized JavaScript origins**: `https://neo-tax-accountant.github.io`
   - Чиққан **Client ID** ни нусхаланг → `CONFIG.CLIENT_ID` га ёзинг.
5. **Credentials → Create credentials → API key**:
   - Чиққан калитни `CONFIG.API_KEY` га ёзинг.
   - **Restrict key** босиб чекланг:
     - Application restrictions → Websites → `neo-tax-accountant.github.io/*`
     - API restrictions → фақат Google Sheets API ва Google Drive API
6. Лойиҳа рақамини (Project number) `CONFIG.APP_ID` га ёзинг.
7. Файлни GitHub'га юкланг, **Ctrl+F5**.

> Эслатма: Testing режимида рефреш токен 7 кунда тугайди — вақти-вақти
> билан қайта кириш сўралади. Бу нормал ҳол, шундай қолдирилган.

## 5. Ҳолат Г — Google Sheets базаси ўчиб кетди

1. Google Drive **саватини** (Trash) текширинг — 30 кун ичида тикланади.
2. Тикланмаса: дастурга киринг, у янги бўш база яратади.
3. Маълумотни архивдан қайтаринг: фирма → **«Фирмани чиқариб олиш (архив)»**
   бўлимидаги тиклаш тугмаси орқали, ҳар бир фирма учун алоҳида.
4. Архив ZIP файллари йўқ бўлса, маълумот қайтмайди. Шунинг учун
   ойлик архив олиш мажбурий (6-бўлим).

## 6. Захира (backup) тартиби — энг муҳим қисм

### Ҳар бир янги версиядан кейин (2 дақиқа)
GitHub'га юклашни Claude ўзи бажаради. Сизнинг ишингиз — берилган
нусхани компьютерингизда сақлаб қўйиш:

```
Dastur/index_в70.html
Dastur/index_в71.html
```

Эски нусхаларни ўчирманг. Бу GitHub йўқолганда ягона ҳимоя.

### Ойига бир марта (10 дақиқа)
1. Ҳар бир фирма учун **«Фирмани чиқариб олиш (архив, ZIP)»** ни босинг.
2. ZIP файлларни компьютерга ва ташқи дискка ёки бошқа Drive папкасига
   кўчиринг.
3. Google Sheets жадвалини очиб, **Файл → Нусха яратиш** — нусха номига
   санани ёзинг.

### Йилига бир марта
Google Cloud созламаларининг скриншотини олиб қўйинг: OAuth client,
Authorized origins, API key чекловлари. 4-бўлимни қайта бажаришда асқотади.

---

## 7. Ноль нуқтадан тўлиқ тиклаш — қисқа рўйхат

Ҳаммаси йўқолган, фақат сақланган `index.html` ва ZIP архивлар бор:

1. GitHub аккаунт → `firmalar` репозиторийси → `index.html` юклаш.
2. Settings → Pages → `main` / root → сайт ишга тушади.
3. Google Cloud: лойиҳа, Sheets + Drive API, OAuth client, API key
   (4-бўлим) → `CONFIG` га ёзиш → қайта юклаш.
4. Сайтга кириш → Google аккаунт → дастур янги база яратади.
5. Ҳар бир фирмани ZIP архивдан тиклаш.
6. Claude API калитини қайта киритиш (дастур ичидаги «Claude AI» бўлими).
   Калит ҳеч қачон кодда сақланмайди, фақат браузерда туради.

---

## 8. Хавфсизлик — тиклашда ҳам амал қилинади

- **Client secret** ҳеч қачон кодга ёзилмайди. Кодда фақат CLIENT_ID,
  API_KEY ва APP_ID бўлади.
- Google Cloud иловаси **Testing** режимида қолдирилади.
- Google Sheets жадвали **Restricted** (фақат рухсат берилганлар) бўлади.
- **ЭЦП (E-IMZO) калити** дастурда ҳеч қачон сақланмайди.
- **Claude API калити** фақат браузернинг localStorage'ида (`fb-claude-v1`).
  Кодга, ҳужжатга ёки GitHub'га ёзилмайди.
- Claude API калитини яратганда **workspace** даражасида яратинг,
  бутун ташкилот даражасида эмас.
- Репозиторий очиқ (public) — ҳар бир юклашдан олдин кодда калит ёки
  парол қолмаганини текширинг.
